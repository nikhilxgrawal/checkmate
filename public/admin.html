🏢 Allowed Orgs

Only people with an email at these domains can register and take part. The org name is derived from the domain (e.g. unicommerce.com → Unicommerce). Removing all domains opens the platform to any email.

🏆 Manage Tournaments

Leave all boxes unchecked (or tick "All orgs") to open the tournament to everyone. Otherwise only the selected orgs can register.

Users can register/unregister only between the two times above. Leave blank for no bound.

Add Match

Every match is played under a tournament. Only users registered to the chosen tournament can be picked — they're added to the roster automatically.

The match automatically goes live at the start time (closing bids and notifying users) and is marked over at the end time.

⬆️ Bulk Upload Matches (.xlsx)

One match per row, players given by email. For each row we create the users (pre-verified, no OTP needed), register both to the tournament (auto-created if new), then create the match. Columns: tournament, gameType, playerA_email, playerB_email, location, startAt, endAt. Best-effort: valid rows apply, invalid rows are skipped and reported. ⬇ Download template
